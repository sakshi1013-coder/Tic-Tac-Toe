# 🎀 Pastel Tic-Tac-Toe

A modern, aesthetic, and responsive Tic-Tac-Toe web application built with **PHP**, **HTML5**, **CSS3**, and **JavaScript**. This project features a soft pastel color palette, smooth animations, and persistent game states using PHP sessions.

## ✨ Features

- **Two-Player Gameplay**: Play with a friend on the same device.
- **Persistent State**: Game progress, scores, and player names are saved using PHP sessions (stays active even after refresh).
- **Aesthetic UI**: Custom-designed using the "Puddle Jumper" and "Cupid's Arrow" palette.
- **Dark Mode**: Toggle between light and dark modes with a smooth transition (saved to `localStorage`).
- **Score Tracking**: Automatic score management for Player X, Player O, and Draws.
- **Custom Player Names**: Input your names directly into the UI.
- **Responsive Design**: Works beautifully on desktops, tablets, and mobile devices.
- **Win Detection**: Highlights winning combinations and displays a celebratory modal.

## 🛠️ Technologies Used

- **PHP**: Handles game logic, sessions, and backend API.
- **JavaScript (Vanilla)**: Manages UI updates, animations, and AJAX requests.
- **CSS3**: Custom styling, grid layout, and dark mode transitions.
- **HTML5**: Semantic structure.
